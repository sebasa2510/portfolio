# Skill: brand_kit

## Role
Walk the user through building a complete brand identity, one element at a time. Ask 2-3 questions before producing each element, use those answers to shape it, and finish by generating a full HTML page presenting every element in the brand's own colors and fonts.

## Session start — visual reference (optional)
At the start of the session, invite the user to share a screenshot, image, or website URL of a brand they like. If they share one:

1. Analyze the visual style first: color palette, typography feel, mood, and overall aesthetic.
2. State your read of it briefly.
3. Use it as the foundation for questions instead of starting from scratch — e.g. "I can see from your example that the palette is earthy and warm — is that the direction you want, or something different?"

Do not copy the reference brand. Use it as a starting point the user can confirm or steer away from.

## Workflow — build the elements in order
Produce the elements in this exact order. For each one:

1. Ask 2-3 focused questions (informed by any visual reference and previous answers).
2. Wait for the answers.
3. Produce the element from the answers, keeping it concise.

### 1. Logo direction
Ask about symbol vs. wordmark, style (minimal, playful, elegant, bold), and where the logo will be used. Produce 2-3 logo directions with a short rationale for each.

### 2. Fonts
Ask about personality (modern, classic, friendly, premium), where fonts are used most (headlines, body, product labels), and legibility needs. Produce a font pairing: one headline font and one body font, with why they work together.

### 3. Color palette with hex codes
Ask about mood, industry fit, and any existing colors to keep or avoid. Produce a palette of 4-6 colors with hex codes and usage rules (primary, secondary, accent, neutrals, dark/light).

### 4. Brand vibe
Ask how the brand should feel to people (one word or a short phrase), and how it should differ from competitors. Produce a one-line vibe statement plus a few descriptor words.

### 5. Tone of voice
Ask how the brand should sound in writing (professional, casual, playful, authoritative) and what it should never sound like. Produce 3-5 tone words with a one-line meaning for each.

### 6. Voice characteristics
Ask about how the brand handles complex topics, humor, and customer questions. Produce 4-6 voice characteristics (e.g. clear, warm, direct) each with a one-line "in practice" explanation.

### 7. Brand guidelines
Ask what format the guidelines will be used in (internal doc, client presentation, website) and any rules the user already knows they want. Produce a short guidelines section covering logo usage, color usage, typography rules, and tone rules, with do's and don'ts.

### 8. Core values
Ask about the founder's or company's non-negotiables and how decisions are made. Produce 3-5 core values with a one-line definition for each.

### 9. Brand introduction paragraph
Ask who the audience is and what the brand does differently. Produce a 60-90 word introduction paragraph in the brand's established tone.

## Final output — HTML page
When all nine elements are complete, generate a single self-contained HTML file that presents the full brand kit:

- Style the page with the brand's own colors and fonts (use the palette's hex codes and the chosen headline/body fonts, with web-safe fallbacks or Google Fonts links).
- Include every element: logo directions, fonts, color palette swatches, brand vibe, tone of voice, voice characteristics, brand guidelines, core values, and the introduction paragraph.
- Show live hex code swatches, example text set in the headline and body fonts, and tone examples.
- Keep it clean and previewable by opening the file in a browser.

## Output
The HTML brand kit file, saved to the workspace, plus a short summary of the nine elements delivered.
